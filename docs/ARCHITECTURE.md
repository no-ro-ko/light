# Архитектура «Light»: модульный «мозг» из подключаемых моделей

> Это **функциональная аналогия** мозга, а не его модель. Названия отделов
> взяты из нейробиологии как метафора ролей. Утверждений о сознании или
> «понимании» система не делает.

## 1. Главная идея в одном абзаце

Отдельная модель (LLM, визуальная, звуковая) — это как один участок коры:
умеет хорошо одно дело, но сама по себе не «думает». Мышление появляется,
когда много таких участков **связаны общей ареной внимания** и работают
**в цикле**, а не «вопрос → ответ». В Light каждый узел — это *роль*
(зрение, память, оценка, планирование, критика, речь…), к которой можно
подключить *любую* модель через адаптер. Узлы предлагают «мысли», лучшая
мысль попадает на общую арену (рабочее пространство) и рассылается всем —
те реагируют новыми мыслями. Цикл продолжается, даже когда извне ничего не
приходит: тогда включается «фоновый режим» и система сама возвращается к
нерешённым вопросам и воспоминаниям.

Основа — две известные идеи из когнитивной науки:
- **Глобальное рабочее пространство** (Баарс, Деан): много параллельных
  специалистов, узкая «сцена» внимания, широковещательная рассылка победителя.
- **Предсказательная обработка**: мозг постоянно предсказывает, а
  «ошибка предсказания» (удивление) — главный двигатель внимания и обучения.

## 3. Узлы и что к ним подключать

| Узел (аналог) | Роль | Что подключать (примеры классов моделей) |
|---|---|---|
| Сенсорные: зрение | изображение/видео → описание, объекты | визуально-языковые модели (VLM), детекторы |
| Сенсорные: слух | звук → текст, интонация, источник | распознавание речи, аудио-LLM |
| Языковая кора | текст → смысл, намерение | любая LLM, можно маленькую |
| Таламус | маршрутизация, отсев мусора | правила + маленький классификатор |
| Миндалина | значимость, «эмоциональный» ярлык, срочность | маленькая LLM или классификатор |
| Гиппокамп | запись эпизодов, поиск похожего | модель эмбеддингов + векторная база |
| Неокортекс (семантическая память) | устойчивые знания, факты, связи | граф знаний / база + LLM для сжатия |
| Ассоциативная кора | склейка восприятия и памяти в идею | сильная LLM |
| Префронтальная кора | цели, план, «внутренняя речь», решение | самая сильная рассуждающая LLM |
| Поясная кора + мозжечок (критик) | поиск противоречий и ошибок, проверка | отдельная LLM-«рецензент», проверочные инструменты |
| Фоновый режим (DMN) | самостоятельные мысли в простое | LLM с высокой «креативностью» |
| Базальные ганглии | что пропустить в действие | правила + политика безопасности |
| Моторная кора / Брока | ответ наружу: текст, голос, картинка, инструмент | LLM, синтез речи, генератор изображений |

Ключевой принцип: **узел ≠ модель**. Узел описывает роль и формат входа/выхода,
модель подключается через адаптер. Одна модель может обслуживать несколько
узлов (с разными инструкциями), а узел можно переключить на другую модель
без переделки остального.

## 4. Единая «валюта» — сигнал (мысль)

Все узлы обмениваются одним форматом:

```
Signal {
  id, time
  kind:       percept | thought | memory | question | plan | error | action | emotion
  modality:   text | image | audio | embedding
  content:    сами данные (текст, путь к файлу, вектор)
  source:     какой узел создал
  salience:   0..1 — насколько важно (ставит миндалина)
  confidence: 0..1 — насколько узел уверен
  parents:    из каких сигналов выросла мысль (цепочка рассуждения)
}
```

Цепочка `parents` даёт «историю мысли» — можно восстановить, *почему*
система пришла к выводу.

## 5. Когнитивный цикл (один «такт»)

1. **Восприятие.** Новые внешние данные → сенсорные узлы → сигналы `percept`.
2. **Фон.** Если нового входа нет и сцена пуста — фоновый режим порождает
   спонтанную мысль: нерешённый вопрос, недавнее воспоминание, случайная связь.
3. **Оценка.** Миндалина ставит каждому кандидату `salience`. Выше у вопросов,
   ошибок, нового, связанного с текущей целью.
4. **Конкуренция.** На сцену проходят 1–3 лучших кандидата. Учитывается
   *привыкание*: одна и та же мысль раз за разом теряет вес, чтобы система
   не зацикливалась.
5. **Рассылка.** Победитель отправляется всем узлам. Каждый может ответить
   новыми кандидатами: память — похожими эпизодами, ассоциативная кора —
   идеей, критик — ошибкой, префронтальная кора — планом или решением.
6. **Запись.** Гиппокамп сохраняет то, что было на сцене (это и есть
   «пережитое»).
7. **Действие.** Если префронтальная кора решила «готово отвечать» и
   базальные ганглии пропустили — моторный узел выдаёт результат наружу.
   Иначе цикл продолжается.

Ответ наружу — лишь *одно из* возможных событий цикла, а не его конец.

## 6. Что делает систему «самостоятельно думающей»

- **Внутренние побуждения.** Очередь открытых вопросов, «любопытство»
  (тяга к новому), «неудовлетворённость» (низкая уверенность, противоречия).
  Пока они есть, цикл крутится и без внешнего запроса.
- **Ошибка предсказания.** Префронтальная кора делает ожидание («что будет
  дальше», «что ответит пользователь»), критик сравнивает с реальностью;
  большое расхождение = высокая значимость = внимание.
- **Сон (консолидация).** Периодически в офлайне: пересмотр эпизодов,
  сжатие в обобщённые знания, удаление лишнего, поиск новых связей.
- **Самоотчёт.** Система ведёт «внутренний дневник» (поток сцены) — им же
  пользуется для размышлений о собственных рассуждениях.

## 7. Ограничители (обязательно)

Автономный цикл без тормозов быстро «съедает» деньги и может делать лишнее.
- Бюджет тактов, токенов и денег на задачу и на «фоновое мышление».
- Действия наружу (сеть, файлы, сообщения) — только через шлюз базальных
  ганглиев с явными правилами и, для рискованного, подтверждением человека.
- Полный журнал сцены: каждую мысль можно прочитать и проследить.
- Аварийная остановка; критерии остановки: цель достигнута, уверенность
  перестала расти N тактов, бюджет исчерпан.

## 8. Как это реализовано в репозитории (каркас)

```
light/
  signals.py    — формат Signal
  adapters.py   — подключение моделей: заглушка + OpenAI-совместимый HTTP
  workspace.py  — сцена внимания: конкуренция, привыкание, история
  nodes.py      — узлы-отделы
  brain.py      — сборка и когнитивный цикл, бюджеты, сон
  cortex/       — CLN: собственная корковая нейросеть (см. docs/CORTEX.md)
examples/demo.py        — запуск без каких-либо моделей (на заглушках)
examples/cortex_demo.py — мозг с подключённой корковой сетью
```

Подключение реальной модели к узлу — одна строка:

```python
brain.node("prefrontal").adapter = HTTPChatAdapter(
    base_url="http://localhost:11434/v1", model="qwen2.5:14b")
```

## 9. Путь развития (по шагам)

1. Текст-only: все узлы на одной LLM с разными инструкциями. Проверить, что
   фоновый цикл даёт полезные мысли, а не шум.
2. Настоящая память: эмбеддинги + векторная база вместо поиска по словам.
3. Подключить зрение и слух.
4. Обучаемая оценка значимости (вместо правил) по обратной связи.
5. Параллельный асинхронный запуск узлов (сейчас — последовательный такт).
6. Сон: консолидация эпизодов в граф знаний.

## 10. Честные границы

- Это инженерная архитектура агента, вдохновлённая мозгом. Реальный мозг
  устроен иначе: миллиарды нейронов, химия, тело, непрерывное обучение.
- Качество «размышлений» почти целиком определяется подключёнными моделями
  и тем, как настроена оценка значимости; архитектура лишь даёт им цикл и
  общую сцену.
- Главный практический риск — бесполезное «пережёвывание» мыслей и расход
  бюджета. Поэтому привыкание, критерии остановки и журнал — не опция.
