# CLN — колонковая слоистая сеть (Columnar Laminar Network)

Нейросеть для «Light», устроенная по образцу коры мозга, а не по схеме
«нейроны → слои → обратное распространение ошибки». Подключается к общему
«мозгу» как ещё один отдел и общается с остальными через ту же сцену внимания.

Код: `light/cortex/`. Тесты: `tests/test_cortex.py`. Пример: `examples/cortex_demo.py`.

## 1. Чем она отличается от обычных нейросетей

| | Обычная сеть (трансформер и т.п.) | CLN |
|---|---|---|
| Базовая единица | искусственный нейрон-сумматор | корковая колонка со слоями L1–L6 и клетками с дендритными ветвями |
| Как учится | обратное распространение ошибки по всей сети, отдельная фаза обучения | только местные правила (связи между вместе работающими клетками крепнут), учится на лету, с одного-нескольких повторов |
| Что передаёт | плотные векторы | разреженные коды: из 256 колонок активны ~12 |
| Время | вход → выход за один проход | непрерывный ритм: на каждом шаге ожидание → сравнение с реальностью → удивление |
| Режимы работы | один | бодрствование / воображение / сон, переключаются «химией» (нейромодуляторами) |
| Структура | фиксирована | связи растут и отмирают (структурная пластичность) |
| Связь с другими частями | вход/выход | прямые связи вверх, обратные подсказки сверху вниз, сигналы удивления на общую сцену |

## 2. Что в мозге → как это сделано

| В мозге | В CLN | Где в коде |
|---|---|---|
| Кортикальная колонка (Маунткасл) | колонка: K клеток, общий вход | `region.py` |
| Слой L4: вход от таламуса, боковое торможение | конкуренция колонок, побеждают k лучших | `step()`, блок L4 |
| Слои L2/3: контекст | одно слово в разных фразах включает разные клетки колонки | `step()`, блок L2/3 |
| Дистальные (боковые) дендриты, предвозбуждение | дендритные сегменты; узнал прошлую картину → клетка «ждёт» | `seg_pre`, `seg_perm`, `_compute_segments()` |
| «Вспышка» колонки при неожиданности | если никто не ждал — активна вся колонка; доля таких колонок = удивление | `anomaly` |
| L5: выход в другие области | растянутый во времени код `output()` | `pooled` |
| L6 → таламус: ожидание | `prediction()` до прихода входа; узел пропускает наверх только удивление | `prediction()`, `node.py` |
| L1, апикальные дендриты: контекст сверху | `apical` смещает конкуренцию колонок | `set_apical()` |
| Прямые и обратные связи между областями | иерархия областей, обратные связи учатся по Хеббу | `connectome.py` |
| Дофамин | сила закрепления; растёт, когда мозг дал ответ | `neuromodulators.py`, `reward()` |
| Норадреналин | растёт от удивления: больше активных колонок, быстрее растут новые связи | там же |
| Ацетилхолин | баланс «верю входу» и «верю ожиданиям»; низкий → воображение и сон | там же, `imagine()` |
| Серотонин | как долго держится контекст сверху | там же |
| Гомеостаз (выравнивание возбудимости) | редко побеждающие колонки получают бонус | `duty`, `boost` |
| Рост и отмирание синапсов | новые синапсы к недавно активным клеткам, мёртвые обрезаются | `_adapt()` |
| Сон: повтор пережитого и ослабление связей (гипотеза синаптического гомеостаза) | повтор эпизодов при низком ацетилхолине, затем всё ослабляется и слабое отмирает | `sleep()`, `downscale()` |
| Тета-ритм | один `step()` = один цикл «ожидание → вход → сравнение → обучение» | `step()` |

## 3. Новое по сравнению с похожими моделями

Честно: каждая часть по отдельности опирается на известные научные идеи.
Это теория колонок Маунткасла, HTM и «тысяча мозгов» Хокинса, предсказательное
кодирование (Рао–Баллард, Фристон), модель нейромодуляторов Дои, гипотеза
синаптического гомеостаза во сне (Тонони–Чирелли) и работы о ритмах мозга
(Бужаки). Проверить, что такого сочетания никто не делал, я не могу:
поиск по литературе не проводился.

Собственные решения этой архитектуры:
1. **Два вида ожидания: «точное» и «размытое».** Ожидание, пришедшее от
   «вспышки» (неопределённого контекста), не считается удивлением, но под
   новый контекст выделяется своя клетка. Без этого разные фразы с общей
   серединой («…потому что свет…») сливались в одну. На тесте после правки
   сеть различает их уже через 2 повтора (`test_context_is_kept`).
2. **Четыре нейромодулятора как ручки режима**, доступные снаружи: общий мозг
   управляет корой «химически» (важное → норадреналин, ответ → дофамин,
   сон → низкий ацетилхолин), а не только данными.
3. **Кора как отдел агентной системы.** Её выход — не вектор, а сигналы на
   сцене внимания: «удивление», «ожидаю дальше», «воображаю». Она участвует
   в общем цикле обдумывания, во сне и в фоновом режиме наравне с языковыми
   моделями.

## 4. Как подключить

```python
from light import Brain
from light.cortex import CorticalNode

brain = Brain()
cortex = brain.attach(CorticalNode("кора"))   # учится прямо в процессе работы
brain.hear("кот спит на тёплом окне")
brain.run()
```

Иерархия областей:

```python
from light.cortex import Connectome, CorticalRegion, WordEncoder
enc = WordEncoder()
net = Connectome()
low = net.add(CorticalRegion("слова", enc.size))
net.add(CorticalRegion("фразы", low.N, columns=128))
net.connect("слова", "фразы")
net.step({"слова": enc.encode("кот")})
```

Для зрения и звука нужен свой кодировщик, превращающий картинку или звук
в разреженный код. Например, признаки от готовой визуальной модели, разложенные
по битам. Область при этом не меняется: она работает с любым разреженным
кодом. Такие кодировщики ещё не написаны.

## 5. Что показали проверки (на этой машине, 4 фразы, 1 область)

- Удивление падает с 1.0 до 0.0 за 2–3 повтора фраз.
- После «небо голубое потому что свет» сеть ждёт «рассеивается», после
  «закат красный потому что свет» — «проходит», то есть помнит контекст.
- По слову «закат» сама продолжает: «красный потому что свет проходит длинный».
- Незнакомая фраза «кот бежит по красному воздуху» даёт удивление ~0.8 и
  попадает на сцену внимания общего мозга с наивысшей важностью.
- После сна выученное сохраняется.

## 6. Границы — где до мозга ещё далеко

- Масштаб: 2 048 клеток против ~16 млрд нейронов коры.
- Нет отдельных импульсов и их точного времени, нет тормозных клеток как
  отдельных элементов (торможение заменено правилом «k победителей»), нет
  глии, сосудов, тела.
- Нейромодуляторы — четыре числа, а не тысячи видов рецепторов.
- Учится последовательностям и ожиданиям, но **не понимает смысл** и не
  рассуждает так, как большие языковые модели. Её роль — быстрая память
  «что обычно бывает дальше», детектор новизны и источник ассоциаций.
  Рассуждение остаётся за другими узлами.
- Проверено на игрушечном наборе. Как она поведёт себя на тысячах фраз
  (ёмкость, путаница), не измерялось.
