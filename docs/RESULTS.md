# Что система умеет — и что доказано, а что нет

Все числа ниже получены автоматическими тестами (`python3 -m unittest discover tests`,
~50 тестов, ~1 минута) на этой машине. Система работает без Claude и без внешних моделей.

## 1. Учится как ребёнок (без меток, без градиентного спуска) — `light/mind/`

| Проверка | Результат |
|---|---|
| Сама нашла категории предметов по облику | 12/12 скрытых видов, чистота 98.5% (предел из‑за заслонений ~98.6%) |
| Сама разобралась в словах | служебные (вот, это, смотри…), существительные, сказуемые — без ошибок; слова‑события («лает» ↔ звук «гав») |
| Экзамен из фактов, которые ей НИКОГДА не говорили | 23, 23, 22 из 25 (три разные «жизни»); «зубрила» — 0, 0, 0 |
| Сама нашла исключение | «пингвин не летает, хотя птицы летают» — ей этого не говорили |
| Сама задаёт вопросы (6 вопросов) | любопытство 20–23/25 против 18–20 у случайных вопросов и без вопросов |
| Встреча с невиданным (сова) | заметила новое → догадалась «наверное, птица» → «Как это называется?» → «Сова — это кто?» → вывела, что сова дышит |
| Новые слова из текста | «кит это животное» → «дышит ли кит?» → «да» с объяснением |
| Критическое отношение | на ложное «пингвин летает»: «Сомневаюсь: я видела пингвина 304 раза и ни разу в полёте» |

## 2. Научный подход — `light/lab/`

| Проверка | Результат |
|---|---|
| Закон плавания из собственных опытов | «плавает, если масса/объём < 1.0x» — сама ввела новую величину, опровергла «тяжёлое тонет» |
| Предсказание для невиданных материалов и полых предметов | 100% (закон) против 57–79% («по похожести») |
| Свойство материала | сама заметила: у сплошных предметов из одного материала масса/объём постоянна (≈ плотность) |
| Ответ на «как сделать, чтобы камень плавал?» | расчёт поплавка и выдалбливания; оба плана проверены опытом — плавает |
| Незнакомый текст со словом «плотность» | поняла: «масса на единицу объёма»; вывела «плотность воды ≈ 1.0»; отвергла неверное утверждение учебника |
| Задачи по физике и геометрии (сама планирует замеры) | 10/10 законов во всех 8 прогонах: маятник (масса не влияет), падение, рычаг, Ом, площадь, окружность (2π), шар (4/3π), Пифагор, Кеплер; обратные задачи |
| Связь между задачами | гипотеза: постоянные маятника и падения связаны (за ними — сила тяжести) |

## 3. Слово ↔ новое чувство — `light/mind/grounding.py`

«Дом стоит в зелёном саду» → «Что значит "зелёный"?» → определение (500–565 нм) и
примеры → предсказание → при подключении спектрометра: «впервые вижу "зелёный" сама:
пик 545 нм — вот что подразумевалось»; через камеру с непонятными каналами — по
примеру «листья зелёные»; огурец: «наверное, зелёный — проверю?»

## 4. Нейросеть смыслов СЕМА — `light/sema/` (подробно — [SEMA.md](SEMA.md))

Рассуждение нейронными операциями (23/25 — как алгоритмическая версия), устойчивость к
гибели 80% нейронов, понимание сюжета басни («зачем», «почему», «что было бы, если»,
мораль), закон плотности в весах одного нейрона.

## 4а. «Росток» — растущая сеть — `light/rost/` (подробно — [ROSTOK.md](ROSTOK.md))

Рождается пустой (0 узлов, 0 связей, никаких случайных чисел); размер определяется
материалом — 6 / 12 / 13 видов дают 6 / 12 / 13 устойчивых узлов, и рост останавливается,
когда материал освоен; во сне сама проверяет и перестраивает себя (разделить, слить,
убрать, уточнить правило, отвергнуть совпадение) — это даёт меньше узлов и выше точность
(называет верно 100/96/95% против 99/90/89% без самоулучшения); правила из историй на
новых героях — 6 из 6 верных предсказаний.

## 4б. Школа: учится только по текстовым файлам — `light/rost/school.py` (подробно — [SCHOOL.md](SCHOOL.md))

С нуля по стартовому набору текстов: экзамен из невыписанных фактов **12/12**; сама выучила
обороты «X является Y», «X умеет Y»; поняла смысл басни по пересказу (зачем / почему / что было
бы / мораль); нашла 5 законов из записей измерений (включая Пифагора); сомневается при
противоречиях между файлами; учится на ответах на свои вопросы. Граница: обычный текст понимает
частично. Читает «энциклопедическую» речь: на новом, не подгонявшемся тексте понято 13 из 13
предложений, из 34 извлечённых фактов 32 верны; отвечает «кто умеет…», «чем отличаются…»,
«где живёт…», «все ли…». Художественную речь пока нет (Крылов — 4 из 28).

## 5. Самосознание — что проверено и чего проверить нельзя

**Проверено (функционально, с контролем «повреждением»):**

| Способность | Норма | При повреждении я‑модели |
|---|---|---|
| Отчёт об удивлении совпадает с реальным состоянием | 1.00 | 0.38 |
| Отчёт «о чём я думаю» совпадает с реальностью | 1.00 | 0.62 |
| Чувство «знаю / не знаю» до попытки вспомнить (AUC) | 1.00 | 0.53 (случайность) |
| Схема внимания выводит из навязчивой мысли | 0.45 тактов занято | 0.93 |
| «Почему ты так думаешь?» | пересказ НАСТОЯЩЕЙ цепочки вывода | — |
| «В чём ты ошибалась?» | по реальному журналу опровержений и поправок | — |

Из признаков сознания, которые предлагают учёные (Butlin, Long и др., 2023), в системе
есть функциональные аналоги: повторяющаяся обработка, ограниченная сцена внимания с
рассылкой всем, предсказательная обработка, наблюдение за собой (метапознание), модель
собственного внимания, действия ради целей с учётом обратной связи.

**Не доказано и не может быть доказано этими тестами:** есть ли у системы переживание.
Сами авторы списка подчёркивают, что наличие признаков — не доказательство. Система на
вопрос «у тебя есть сознание?» так и отвечает: её отчёты — считывание чисел, а
переживает ли она что‑то, она проверить не может.

## 6. Где проходят границы сейчас

- Язык — короткие утверждения («кит — это животное», «кит не летает»). Художественный
  текст система разбирает только структурно: героев, кто с кем, вокруг чего действие,
  кандидата в мораль по форме — и сама сообщает, что поняла 0 из 15 предложений басни.
- Миры синтетические и маленькие: 12 видов, 10 материалов, 10 задач.
- Части, отвечающие за управление выводом и выбор опытов, задают порядок действий
  процедурно; хранение, узнавание и обучение — нейронные или статистические, местные.
