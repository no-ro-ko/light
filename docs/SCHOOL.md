# Школа «Ростка»: кладёте тексты в папку — он учится

Код: `light/rost/organism.py`, `language.py`, `knowledge.py`, `rules.py`, `measures.py`,
`syntax.py`, `causes.py`, `narrative.py`, `school.py`. Стартовый набор текстов: `curriculum/`. Тесты: `tests/test_school.py`, `test_reading.py`, `test_causes.py`, `test_narrative.py`.
Работает без Claude и без внешних моделей.

## Как пользоваться

```bash
python3 -m light.rost.school начать      # положить стартовый набор текстов во «входящие»
python3 -m light.rost.school учиться     # прочитать новое, поспать, записать ответы
python3 -m light.rost.school следить     # учиться само, как только в папке появятся файлы
python3 -m light.rost.school спросить "Дышит ли кит?"
python3 -m light.rost.school беседа      # вопросы (с «?») и новые знания словами
```

| Папка | Что там |
|---|---|
| `данные/входящие/` | сюда кладёте любые `.txt` (строки с «?» — вопросы к системе) |
| `данные/изучено/` | сюда система переносит прочитанное |
| `данные/ответы/ответы.txt` | ответы на вопросы из файлов — с объяснениями |
| `данные/ответы/мои_вопросы.txt` | что ей непонятно и что она хочет узнать |
| `данные/ответы/отчёт.txt` | как она выросла и сколько поняла в каждом файле |
| `данные/ответы/журнал.txt` | что она изменила в себе во сне |
| `данные/росток.pkl` | память между запусками |

Ответить на её вопросы — обычным текстовым файлом во «входящие» («Прямоугольник это фигура.»).

## Что вырастает из текстов

| Что | Как |
|---|---|
| Формы слов и окончания | окончание выучивается, когда встречается у многих основ; «животное / животные / животным» сводятся в одно слово |
| Обороты речи | если между двумя понятиями с уже известной связью стоят одни и те же слова — это новый оборот («X является Y», «X умеет Y», «X не умеет Y»); принятый оборот сам добывает новые факты |
| Знания | понятия, роды и свойства — с источником каждого |
| Рассуждение | цепочки родов, исключения, обобщения, осторожное «нет, наверное», честное «не знаю» |
| Правила историй | вырастают из повторяющихся переходов, во сне проверяются, уточняются условием или отбрасываются как совпадения |
| Смысл истории | «зачем», «почему», «что было бы, если бы», мораль |
| Законы | из записей измерений: поиск постоянного сочетания величин (в том числе Пифагор — суммой квадратов) |
| Слова-ощущения | «зелёный — это свет 500–565 нм», примеры «листья зелёные» |
| Свои вопросы | незнакомые слова, понятия без рода, просьбы о новых измерениях, противоречия |
| Сомнения | «в одном файле сказано X, в другом — не X: как правильно?» — знание не затирается |

**Во сне — самоулучшение:** выучить окончания и обороты, **перечитать всю память заново
с выросшим языком** (и понять больше, чем при первом чтении), проверить правила, найти законы.

**Врождённое (честно):** что значат «не», «это», «—», «ли» и ~50 самых частых служебных слов
(предлоги, союзы, местоимения). Всё остальное — из прочитанного.

## Что измерено (с нуля, только по текстам стартового набора)

| Проверка | Результат |
|---|---|
| Экзамен из фактов, которых нет ни в одном тексте | **12 / 12** («дышит ли кит?» — через вычитанный ею самой оборот «является»: кит → млекопитающее → животное → дышит) |
| Выученные обороты | «X является Y» (подтвердился на 12 известных парах), «X умеет Y», «X не умеет Y» |
| Смысл басни (по пересказу) | «зачем лиса хвалит ворону», «почему сыр падает», «что было бы, если бы лиса не хвалила ворону», мораль «лесть» |
| Законы из записей | маятник (масса не влияет), падение, закон Ома, площадь круга, **диагональ² = ширина² + высота²**; прямые и обратные задачи |
| Рост по файлам | формы слов 61 → 317, понятия 31 → 56, правила 0 → 5, законы 0 → 5 |
| Противоречие между файлами | сомнение с обоими источниками и вопрос «как правильно?» |
| Учёба на ответах | «прямоугольник — фигура», «квадрат — прямоугольник» → «является ли квадрат фигурой?» — «да» |
| Перезапуск | всё помнит; уже прочитанный файл пропускает |

## Чтение обычного текста (сложные фразы)

Сложная фраза разбирается на простые высказывания, а их система понимает своими оборотами.

| Фраза | Что система поняла |
|---|---|
| «Киты — крупные морские млекопитающие» | кит — млекопитающее; кит крупный; кит морской |
| «Они дышат воздухом и выкармливают детёнышей молоком» | «они» = киты; кит дышит воздухом; кит выкармливает детёнышей молоком |
| «Акулы дышат жабрами, а киты дышат лёгкими» | две фразы с разными подлежащими |
| «Летучая мышь — это млекопитающее, которое умеет летать» | понятие из двух слов «летучая мышь»; придаточное — о ней же |
| «Крокодилы — опасные хищники, которые живут в реках. Они откладывают яйца на берегу» | хищники, опасные, живут в реках, откладывают яйца на берегу |
| «Коровы, козы и овцы дают молоко» | три подлежащих |
| «Все птицы откладывают яйца. Некоторые птицы не летают» | первое — про всех (пингвин тоже откладывает); второе — только про некоторых, без ложного обобщения |
| «Пингвины не летают, но отлично плавают» | подлежащее второй части — то же |

Как она отличает название от действия или признака — из **собственных знаний**: какие окончания
бывают у слов на месте «кто» в уже понятых фактах, а какие — на месте «что делает / какой»;
плюс устройство русской группы слов (признаки стоят перед главным словом). Подсказки из надёжно
понятых простых фраз — сильные; из разбора сложных — слабые и пересчитываются во сне (ранняя
ошибка не закрепляется навсегда). Слова с разной ролью («синица» и «синий», «белка» и «белые»,
«живое» и «живут») в одно слово не сливаются.

Новые виды вопросов: «Кто умеет летать?», «Какие птицы не летают?», «Что умеет дельфин?»,
«Что ты знаешь о пчеле?», «Чем отличаются кит и акула?» (кит — млекопитающее, дышит лёгкими;
акула — рыба, дышит жабрами), «Чем похожи кит и дельфин?», «Где живут крокодилы?», «Все ли
птицы летают?» (нет: курица, пингвин, страус). Точное следует общее: «откладывают яйца на берегу»
⇒ «откладывают яйца».

**Проверка на новом тексте, который не подгонялся под систему** (жирафы, крокодилы, ёжики, орлы,
змеи, бабочки): понято 13 из 13 предложений, извлечено 34 факта, из них **32 верны** и 2 частично
неверны («зимой ёжики» как одно понятие; «змеи не имеют» без «ног»). Потеряно «некоторые змеи
ядовиты». Тогда не связались формы «орёл/орлы» (беглая гласная) и «даёт/дают» (короткая основа);
теперь система выучила эти чередования, и «Дышит ли орёл?» — «да» (орлы → птицы → животные).

## Причины из обычного текста

«Если …, то …», «когда …, …», «… потому что …», «… так как …», «… поэтому …» — связь
«положение дел → следствие».

| Вопрос | Ответ системы |
|---|---|
| Почему трава растёт? | потому что земля мокрая; а земля мокрая, потому что идёт дождь |
| Что будет, если вазу толкнуть? | ваза падает → ваза разбивается |
| Что будет, если кошка не ест? | наверное, кошка слабеет (сказано про животных; кошка — животное) |
| Почему днём светло? | потому что солнце светит |

## Рассказы обычной речью (`light/rost/narrative.py`)

Раньше истории читались только из коротких фраз («Лиса хвалит ворону. Ворона радуется.»).
Теперь — из обычного повествования: прошедшее время, местоимения, инверсия, наречия, места,
«стала хвалить», прямая речь. Литературный пересказ басни (`13_басня_литературно.txt`):

> Однажды ворона нашла кусок сыра. Она села на высокую ель и крепко держала сыр в клюве. Мимо
> бежала голодная лиса. Она увидела сыр и сразу захотела его. Хитрая лиса подошла к ели и стала
> хвалить ворону: «Какие у тебя чудесные перья! …» Ворона очень обрадовалась. Глупая птица громко
> запела. Сыр выпал из клюва. Лиса схватила сыр и убежала.

| Что в тексте | Как понято | Откуда система это знает |
|---|---|---|
| «крепко **держала** сыр» | ворона держит сыр | «держа-ла» ~ «держи-т»: одна основа, другая гласная (чередование) |
| «Мимо бежала голодная **лиса**» | лиса бежит | «кто» после действия: форма «лиса» — начальная (так слово начинает фразы), «голодная» — признак |
| «**Она** увидела сыр и сразу захотела **его**» | лиса увидела сыр; лиса хочет сыр | «она» — тот, кто действовал последним; «его» — участник, подходящий по роду |
| «стала **хвалить** ворону» | лиса хвалит ворону | из двух действий подряд главное — последнее |
| «Глупая **птица** запела» | ворона поёт | в рассказе есть ворона, а ворона — птица |
| «…ворону: «Какие у тебя перья!»» | — | прямая речь — сказанное, не событие |

Во всём тексте нет ни одной фразы, на которой работали прежние истории. Опыт с короткими
фразами переносится на обычную речь. **Учёба на своих вопросах**: если читать без простого
пересказа (04) и без словаря (14), система разбирает рассказ, но на «Зачем лиса хвалила ворону?»
честно не отвечает и спрашивает: «Что значит „захотела“?», «…„обрадовалась“?», «…„запела“?»,
«…„выпал“?», «…„схватила“?». Ответ — файл `14_слова.txt` («Запела — значит поёт.» …). После сна
она перечитывает рассказ и отвечает: «Чтобы получить сыр: лиса хочет сыр, и это ведёт к цели:
лиса хвалит ворону → ворона радуется → ворона поёт → сыр падает (ведь ворона держит сыр) → лиса
берёт сыр». Отвечает и «почему сыр упал», «что было бы, если бы…» и о морали.

**Что выучено, а не задано.** Всё это — статистика её собственного чтения:
- какие окончания у действий: во фразах, где «кто» — знакомое название, следующее слово — действие;
- у кого какой «род»: «она села» → «-ла» бывает при «она»; «лиса бежала» → лиса — «она»; для
  незнакомых — по последней букве, как у знакомых героев;
- признаки: слова, стоявшие перед названием («крупные морские млекопитающие»), и их семьи форм;
- места: что стояло после предлога («на стол», «по полу»);
- рассказ или описание: в рассказе формы действий говорят, кто действовал («села», «упал»), и
  герои меняются ролями («держала сыр» → «сыр выпал»). Энциклопедия («Киты дышат…») рассказом
  не считается, и её сведения остаются общими знаниями. А «лиса схватила сыр» — знание про этот
  рассказ, не про всех лис.

Врождённое (честно): он/она/оно/они и его/её/их, предлоги, союзы, «не», «хочет» — желание,
«X — значит Y» и «X — то же, что Y» — два слова об одном, частица «-ся/-сь», кавычки «…» —
прямая речь, «…, что …» — пересказ сказанного.

### Проверка на рассказах, которых система не видела

Разбор проверялся и исправлялся на трёх новых рассказах. Поэтому их результат после
исправлений — **не слепая проверка**. Четвёртый рассказ и его эталон записаны до запуска и
ни разу не подгонялись.

| Рассказ | Первая попытка | После исправлений |
|---|---|---|
| девочка и яблоко | «Зачем мальчик хвалил девочку?» — не ответила: «её» отнесено к яблоку, «рядом» принято за героя | «Чтобы получить яблоко…» |
| сорока и конфета (записан до исправлений) | не ответила: «она» — конфета, «стала его хвалить» не разобрано | «Чтобы получить конфету…» |
| кот и кувшин (эталон — 9 событий, записан до запуска) | верно 3 из 9 | верно 8 из 9, ложных нет |
| **щенок и кошка** (слепой; эталон — 10 событий) | **верно 6 из 10** | — |

Где ошибается слепой рассказ: присказка «Жил-был маленький щенок» не понята, поэтому «он
нашёл мяч» отнесено к мячу; незнакомый «щенок» проигрывает знакомому «мячу» в «Щенок толкнул
мяч»; «свой мяч» — «свой» принят за героя. Незнакомые глаголы («толкнул», «поднял»,
«вылакал») система не угадывает. Она спрашивает о них, а мотив иногда выводит своими
правилами: в рассказе написано «поднял», а она выводит «мальчик берёт яблоко».

**Оригинал Крылова**: события найдены в 12 строках из 28, но верны из них примерно три («лиса
бежит», «ворона каркнула», «сыр падает»). Остальное перепутано: «сыр видит лисица»,
«хвостом говорит». Похвала у Крылова — прямая речь, желание — «сыр пленил», бегство —
идиома «была такова». По одному оригиналу на «зачем» система не отвечает — и не делает вид,
что поняла.

## Честные границы

- **Чтение рассказов — пока простое повествование.** Поняты прошедшее время, местоимения,
  инверсия («Мимо бежала лиса»), «стала хвалить», места, прямая речь. Не поняты присказки и
  идиомы («жил-был», «была такова»), притяжательные («свой»), творительный падеж в роли «чем»
  («носом»), причастные и деепричастные обороты, то, что подразумевается в прямой речи (у Крылова
  похвала — только в словах лисы).
- **Незнакомые герои.** Если о существе ничего не известно («щенок»), система хуже понимает,
  кто действует. Помогает простая история или фраза «Щенок — это собака».
- **Незнакомые глаголы и синонимы** не угадываются: «толкнул» — не «толкает», «схватила» — не
  «берёт», пока не объяснят («Схватила — значит берёт»). Система спрашивает о них сама.
- **Знания о мире** у неё только из прочитанного: что молоко — в кувшине, она не знает, поэтому
  «зачем кот толкнул кувшин» — без ответа.
- **Морфология учится по малому объёму текста.** Формы иногда сводятся неверно. Чередования —
  только самые частые: беглая гласная, гласная перед окончанием, «-ся/-сь».
- **Новые обороты выучиваются, только когда связывают уже известное.** Поэтому учить её
  лучше «лесенкой»: сначала простые тексты, потом сложнее.
- **В текстовом режиме нет зрения**: «зелёный» понят по определению, а не увиден.
- **Порядок действий** (чтение → сон → перечитывание) задан программой; что именно выучить —
  решает материал.

## Что дальше

Незнакомые герои («жил-был …»), притяжательные и творительный падеж; затем — подразумеваемое в
прямой речи (похвала, просьба, обман), чтобы понимать оригинальную литературу, а не пересказ;
признаки-сравнения («больше, чем»).
