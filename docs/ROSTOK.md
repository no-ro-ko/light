# «Росток» — сеть, которая рождается пустой и растёт по материалу

Код: `light/rost/`. Тесты: `tests/test_rost.py`. Пример: `python3 examples/rostok_demo.py`.

## Чем это отличается от обычных нейросетей

| | Обычная нейросеть (в том числе большая языковая модель) | «Росток» |
|---|---|---|
| Рождение | заранее создана огромная матрица параметров, заполненная случайными числами | **пусто**: ни одного узла, ни одной связи, никаких случайных чисел |
| Откуда структура | размер выбран человеком до обучения | узел появляется, когда опыт его потребовал; связь — при первом совпадении |
| Как учится | параметры подгоняются градиентным спуском, пока ответы не станут подходящими | узел — след пережитого (пример, затем уточняемое среднее); связь крепнет при повторении (правило Хебба) |
| Размер | один и тот же при любом материале | **определяется материалом**; когда материал освоен, рост останавливается |
| Изменение себя | архитектура неизменна | **во сне сама пробует перестроиться**, проверяет на своей памяти и оставляет только улучшения |

## Как устроена

**Поля узлов (ансамблей).** Образы — узлы, каждый из которых хранит, как выглядит «такое».
Слова — узлы, появляющиеся при первом звучании. Правила — узлы со схемой перехода
«X толкает Y → Y падает» (с переменными вместо героев). Слоёв нет: узлы разных полей
связаны напрямую.

**Рост.** Встретилось то, на что не похож ни один узел, — вырастает новый. Узел, у которого
пока мало примеров, «размыт» и шире принимает похожее; с опытом становится точнее.

**Самоулучшение во сне** — самоэксперименты над собственным устройством:
- *разделить* узел, если его упорно называют двумя словами И эти группы выглядят
  по-разному (пингвины ≠ воробьи; а «мяч» и «игрушка» — те же мячи, их не делит);
- *слить* два близких узла, которые называют одинаково;
- *убрать* узел-случайность (заслонённый или странный экземпляр);
- *стать внимательнее или терпимее* к различиям — вырасти заново по памяти с другой мерой;
- *уточнить правило* условием, которое было во всех случаях, где оно сбылось;
- *отказаться от правила*, которое сбывается редко, — это совпадение, а не причина.

Каждое изменение проверяется **честно**: перестройка строится по одной половине
воспоминаний, а проверяется на другой. Без этого сеть на ранних шагах «раздувалась» до
40 узлов, подгоняя себя под знакомые случаи; с этим — нет. Оценка без учителя: «угадала
бы я прозвучавшее слово, когда показали на вещь?» плюс небольшая цена за каждый узел.
Каждое принятое изменение записывается в журнал с числами «было → стало».

## Что измерено (тесты)

| Проверка | Результат |
|---|---|
| При рождении | 0 узлов, 0 слов, 0 связей |
| Случайность | нет: тот же материал → та же сеть, тот же журнал |
| Размер по материалу: 6 / 12 / 13 видов | **6 / 12 / 13** устойчивых узлов |
| Рост останавливается, когда материал освоен | после ~500 моментов 12 узлов, после 2000 — те же 12 |
| Только рост против роста с самоулучшением (3 прогона) | узлов 17, 21, 18 → **12, 16, 12**; называет верно 99%, 90%, 89% → **100%, 96%, 95%** |
| Правила из историй | выросли сами; «X держит → X поёт» и «X хочет Y → Y падает» отвергнуты как совпадения; «X толкает Y → Y падает» уточнено: «…, а Y шатается» |
| Новые истории с новыми героями | с самопроверкой **6 из 6** предсказаний верны; без неё 6 из 9; «зубрила» — 0 предсказаний |

Пример журнала (прогон 2):
```
[200] разделила узел #2: его называют по-разному (пингвин, воробей): самооценка 0.508 → 0.395
[400] слила узлы #9 и #12: похожи и зовутся одинаково («человек»): самооценка 0.246 → 0.231
уточнила правило «X толкает Y → Y падает» (сбывалось 2 из 5) → «X толкает Y, а Y шатается → Y падает» (2 из 2)
```

## Честные границы

- **Набор способов перестройки задан** (разделить, слить, убрать, подстроить, уточнить,
  отказаться). Когда и что применить, сеть решает сама по самопроверке; новых способов
  перестройки она не изобретает.
- **Миры маленькие и придуманные**; «зрение» — набор признаков, а не настоящие картинки.
- **«Росток» пока выращивает образы, слова и правила.** Остальные способности системы
  (рассуждение цепочками, законы, любопытство, кора CLN, СЕМА) работают рядом, но ещё не
  перенесены на «Росток». Это следующий шаг: чтобы вся система стала одной растущей сетью.
- Самооценка ошибки (~24%) — внутренняя мера: в неё попадают случаи, когда вещь назвали
  родовым словом («смотри, животное»). Настоящая точность называния — 95–100%.
