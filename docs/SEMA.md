# СЕМА — нейросеть смыслов

Нейросетевая архитектура, в которой знания, рассуждение, понимание сюжета и законы
выполняются **нейронными операциями** с **местным обучением** — без градиентного спуска.
Код: `light/sema/`. Тесты: `tests/test_sema.py`.

## Из чего состоит

| Часть | Что это в нейронных терминах | Где |
|---|---|---|
| Понятие | рисунок активности популяции: вектор из D значений ±1 (D = 512–2048) | `core.Space` |
| Связывание «роль ⊗ участник» | поэлементное умножение (мультипликативное взаимодействие на дендритах) | `Space.bind` |
| Событие («лиса хвалит ворону») | наложение связок: агент⊗лиса + действие⊗хвалить + объект⊗ворона, с порогом | `EventMemory.event` |
| Память | плотная ассоциативная сеть (современная сеть Хопфилда): один нейрон хранит один след в синапсах; узнавание по частичному намёку | `EventMemory` |
| Очистка | аттракторная память понятий: шумный рисунок → ближайшее понятие | `Space.cleanup` |
| Вывод | цикл «запрос → узнавание → развязывание → очистка → новый фокус»; ближнее проверяется раньше дальнего (так работают исключения) | `reasoner.NeuralReasoner` |
| Причинные правила | схемы с переменными, извлечённые из разных историй; надёжность проверяется с учётом условий («после ≠ вследствие») | `story.StoryMind` |
| Закон в весах | нейрон на логарифмах входов, правило дельты (Видроу–Хофф) | `neuron.py` |
| Восприятие | растущий слой прототипов с бдительностью (в духе ART Гроссберга) | `light/mind/perception.py` |
| Кора последовательностей | колонки со слоями, дендритные сегменты, нейромодуляторы | `light/cortex/` |

## Что она делает (измерено)

- **Рассуждение на экзамене из никогда не сказанных фактов:** 23/25 — столько же, сколько
  у алгоритмической версии на тех же знаниях. Объяснение — путь фокуса по памяти:
  «пингвин — это птица (сила 0.50) → птица — это животное (0.50) → помню: животное дышит».
- **Устойчивость к повреждению** (как у мозга): при D = 512 гибель 50% и 80% нейронов —
  без потерь (23/25), при 95% — резкий спад (11/25). При D = 2048 даже 90% — 23/25.
- **Смысл сюжета** на басне, которую сеть не видела (пересказ простыми фразами), по
  правилам, извлечённым из историй про других героев:
  - «Зачем лиса хвалит ворону?» → чтобы получить сыр: хвалит → ворона радуется → поёт →
    сыр падает (ведь ворона держит сыр) → лиса берёт сыр (ведь лиса хочет сыр);
  - «Почему сыр упал?» → цепочка причин назад до похвалы;
  - «Что было бы, если бы ворона не пела?» → сыр не упал бы, лиса не взяла бы сыр;
  - мораль → «кто-то хвалит другого, чтобы получить то, что есть у другого; по
    определению это „лесть“» — то, о чём мораль Крылова;
  - совпадения отвергаются: «держит → поёт» (2 из 5) и «хочет → падает» (2 из 4).
- **Закон в весах:** логистический нейрон на [log масса, log объём] приходит к весам
  (−1.00, +0.97) — решает отношение массы к объёму, граница ≈ 1.06 (истина 1.0);
  на невиданных материалах 100%. Линейный нейрон находит «период ≈ 2.01·длина^0.51,
  масса не влияет».

## Что в ней нового, а что известно

Известно и взято за основу: векторно-символические архитектуры (Канерва, Плейт;
семантические указатели Элиасмита), современные сети Хопфилда, ART Гроссберга, правило
дельты, анализ планов и целей в понимании историй (Шенк и Абельсон).

Своё: соединение этих частей в одну систему, где те же коды событий служат и для
вывода по иерархии понятий, и для извлечения причинных правил с условиями и проверкой
надёжности, и для ответов «зачем / почему / что было бы, если» и морали; плюс связь с
глобальным рабочим пространством, я-моделью и любопытством остальной архитектуры.
Утверждать, что такого сочетания никто не делал, я не могу — обзора литературы не было.

## Честные границы

- **Управление выводом — процедура, а не обученная сеть.** Порядок запросов (сначала
  свойство, потом род, потом закрытый мир) задан кодом — как будто «префронтальная кора»
  написана вручную. Хранение, узнавание и развязывание — нейронные.
- **Знания для экзамена переносятся из алгоритмического разума** (`load_from`): сама
  СЕМА пока не учит язык из сцен — это делает `light/mind/`.
- **Сюжеты — на упрощённом языке** («лиса хвалит ворону»). Настоящий текст Крылова сеть
  не разбирает: для живого русского языка с падежами, инверсиями и метафорами нужен
  несравнимо больший языковой опыт (или подключённая языковая модель).
- Правило извлекается, если повторилось хотя бы в двух историях; в реальном мире
  потребуются тысячи историй и более тонкая статистика причинности.
